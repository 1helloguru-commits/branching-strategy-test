# MuleSoft Customer API - Sample

This is a practice MuleSoft API project using RAML 1.0.

## Structure

- `src/main/resources/api/customer-api.raml` - API specification
- `src/main/resources/examples/` - request/response examples
- `pom.xml` - Maven/Mule application skeleton
- `exchange/api-fragment/` - placeholder for Exchange-related API assets

## Endpoints

GET    /customers
POST   /customers
GET    /customers/{customerId}
DELETE /customers/{customerId}

This sample is intended as a starting point for Anypoint Studio/API Manager/Exchange practice.
